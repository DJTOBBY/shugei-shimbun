# ネタ帳（手芸新聞・取材メモ）

このファイルは、手芸新聞の新号を作る際のネタ候補を溜めておく内部メモです。
公開ページ（index.html / backnumbers.html / issues/ / feed.xml / archive.html / sitemap.xml）とは独立していて、
ここに載っている内容がそのまま紙面になるわけではありません。新号を書く人（編集部）が、
ここから使えそうなネタを選んで取材・執筆します。

## 記入フォーマット

新しい発見が一番上に来るように追記してください。

```
## YYYY-MM-DD発見
- **[ジャンル]** 見出し（仮）
  - 概要: 1〜2文の要約
  - 出典: [サイト名](URL)
  - 想定面: メモ（任意。例：1面候補／市場面向き／文化面向き など）
  - 状態: 使用済み（2026-08-16号）
```

ジャンルの例：催事・展示会／毛糸・編み物／ビーズ・ジュエリー／刺繍・刺し子／
キルト・パッチワーク／新商品・新刊／市場データ／作家・クリエイター／海外トレンド

ネタが実際に号で使われたら、そのエントリの「状態」を `未使用` から
`使用済み（YYYY-MM-DD号）` に書き換えてください。曖昧な情報や出典不明の話は載せないこと。
